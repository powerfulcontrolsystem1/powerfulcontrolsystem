Controladores locales

Agrega controladores GPIO para repartir lamparas, motobombas, puertas o equipos entre varias placas.

Para Raspberry GPIO con túnel saliente puede dejarse vacío; PCS identifica la placa con su ID seguro.

Siri se integra de forma portable publicando entidades desde Home Assistant hacia Apple Home con HomeKit Bridge. Matter, Hue, Tuya, Zigbee2MQTT y Z-Wave JS pueden operar por Home Assistant o gateway compatible.
Instalacion desde la Raspberry: abre PCS en el navegador de la Raspberry Pi, entra a esta pagina y pulsa Generar instalador. Luego ejecuta una sola vez el archivo descargado con sudo sh ~/Downloads/instalar-pcs-domotica-*.sh. El instalador crea el servicio y la Raspberry mantiene el tunel HTTPS saliente hacia el VPS; no requiere abrir puertos en el router.
